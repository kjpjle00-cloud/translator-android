아산남성초 통역기 Android 통합판 v0.2

목표
- 지금까지 만든 웹 통역기 기능을 그대로 사용하면서 이어폰 분리 출력 기능을 Android 네이티브로 추가합니다.
- 직원이 한국어로 말한 결과(외국어)는 휴대폰 스피커로 들려줍니다.
- 민원인이 외국어로 말한 결과(한국어)는 연결된 이어폰/헤드셋으로만 들려줍니다.

현재 통합된 기존 통역기 기능
- 수동대화 / 자동대화
- 3초 무음 후 자동 번역
- 반복 인식 확인/보호
- 기본 민원문장 전체 수정
- 학교 이름 설정 및 기본문구 학교명 자동 변경
- 즐겨찾기
- 내 문구 등록/수정/삭제
- 기본 언어 및 사용자 언어 추가/삭제
- 민원문장 읽어주기
- 직접입력 번역
- 기존 translator-942.pages.dev UI와 설정 사용

Android 추가 기능
- 이어폰 분리 모드 기본 ON
- 외국어 TTS -> 휴대폰 내장 스피커
- 한국어 TTS -> 블루투스/유선/USB 이어폰
- 이어폰 미연결 시 한국어 번역을 휴대폰 스피커로 대신 재생하지 않음
- Android SpeechRecognizer 사용
- 이어폰 연결/해제 상태 실시간 표시
- 우측 상단의 '이어폰 분리 ON' 버튼을 눌러 일반출력/분리출력 전환 가능

중요
- 이 APK는 기존 웹앱 https://translator-942.pages.dev/ 를 WebView에서 불러오기 때문에, 웹앱 기능 수정 내용도 그대로 이어집니다.
- 자유 번역은 기존 Apps Script 서버를 사용하므로 인터넷 연결이 필요합니다.
- Android SpeechRecognizer는 입력 마이크 장치를 앱에서 완전히 고정할 수 없어서, 블루투스 이어폰 연결 시 음성 입력이 이어폰 마이크를 사용할 가능성이 있습니다. 실제 Z Fold 7에서 확인이 필요합니다.

Android Studio에서 APK 만들기
1. Android Studio 설치
2. 이 폴더(NamseongTranslatorEarphone_v0.2_integrated)를 Open
3. SDK 35 설치 안내가 뜨면 설치
4. Gradle Sync 완료
5. Build > Build App Bundles or APKs > Build APKs
6. 생성 파일: app/build/outputs/apk/debug/app-debug.apk
7. 지폴드7에 APK를 전송하여 설치

최초 실행
1. 마이크 권한 허용
2. 블루투스 이어폰 사용 시 근처 기기/블루투스 연결 권한 허용
3. 이어폰 연결
4. 우측 상단 '이어폰 분리 ON · 이어폰 연결됨' 확인
5. '내가 말하기' -> 외국어가 휴대폰 스피커로 출력되는지 확인
6. '말씀하세요' -> 한국어 번역이 이어폰으로만 출력되는지 확인
7. 자동대화도 같은 경로로 번갈아 출력되는지 확인

테스트 우선순위
A. 수동대화
- 직원 한국어 -> 외국어 스피커
- 민원인 외국어 -> 한국어 이어폰
B. 자동대화
- 직원 -> 민원인 -> 직원 순환
- 각 차례의 출력 장치 확인
C. 이어폰 제거
- 한국어 TTS가 폰 스피커로 새지 않아야 함
D. 기존 기능
- 기본문구 수정, 학교명 변경, 즐겨찾기, 내 문구, 언어 추가/삭제 정상 동작

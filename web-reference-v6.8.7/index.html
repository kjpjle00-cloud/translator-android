＋ 언어 추가/관리
필요한 언어를 직접 추가할 수 있습니다. 번역코드는 Google 번역에서 사용하는 언어코드, 음성코드는 휴대폰 음성인식/TTS 로케일을 입력합니다.
예: 프랑스어 fr / fr-FR, 독일어 de / de-DE, 포르투갈어(브라질) pt / pt-BR, 힌디어 hi / hi-IN. 빠른 입력 목록에 없는 언어도 직접 입력할 수 있습니다.
추가 언어 번역을 사용하려면 ZIP의 Apps Script Code.gs도 v6.0으로 다시 배포해야 합니다.
추가한 언어는 이 스마트폰에 저장됩니다. 자유번역은 Apps Script 서버와 해당 언어 지원이 필요합니다.
직접 추가한 언어 · 각 항목의 삭제 버튼으로 제거할 수 있습니다.
※ 모든 언어가 음성인식·읽어주기를 지원하는 것은 아닙니다. 번역은 되지만 음성 기능이 없는 언어도 있을 수 있습니다. 추가 언어의 자주 쓰는 민원문장은 처음 선택할 때 자동 번역되어 기기에 저장됩니다.

기본문구 수정 내용은 이 기기에 저장됩니다.
⭐ 내 문구 등록
행정실에서 자주 쓰는 문구를 직접 등록할 수 있습니다. 한국어로 등록하면 즐겨찾기에 자동 추가되고, 현재 선택한 언어로 처음 사용할 때 자동 번역되어 이 휴대폰에 저장됩니다.
등록한 문구는 이 스마트폰에 저장됩니다. 주민등록번호·여권번호 등 민감정보는 문구로 저장하지 마세요.

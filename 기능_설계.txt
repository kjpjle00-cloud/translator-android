아산남성초 외국인 민원 통역기 Android 통합판 v0.2

[기본 원칙]
- 기존 웹 통역기 주소: https://translator-942.pages.dev/
- 기존 웹 통역기의 기능을 그대로 사용한다.
- Android 네이티브는 음성인식과 TTS 출력 장치 제어를 담당한다.

[웹 통역기에서 그대로 사용하는 기능]
1. 수동대화 / 자동대화
2. 3초 무음 후 번역 시작
3. 반복 인식 방지 로직
4. 기본 민원문장 전체 수정
5. 학교 이름 설정 및 기본문구 자동 반영
6. 즐겨찾기
7. 내 문구 등록/수정/삭제
8. 기본/사용자 언어 추가 및 삭제
9. 인사·민원문장·읽어주기
10. PC/모바일 대응 UI

[Android 네이티브 추가 기능]
- 이어폰 분리 모드 기본 ON
- 직원의 한국어 -> 외국어 TTS: 휴대폰 내장 스피커
- 민원인의 외국어 -> 한국어 TTS: 연결된 이어폰/헤드셋
- 이어폰 미연결 시 한국어 TTS를 휴대폰 스피커로 흘리지 않음
- Android SpeechRecognizer로 음성인식
- 상단 작은 상태버튼에서 이어폰 분리 모드 ON/OFF 전환 가능
- 이어폰 연결/해제 상태 실시간 갱신

[주의]
- 번역 자체는 기존 translator-942 웹앱과 Apps Script 번역 서버를 사용하므로 자유 번역에는 인터넷이 필요하다.
- 이어폰 입력 마이크까지 강제로 휴대폰 내장 마이크로 지정하는 기능은 Android SpeechRecognizer 제약상 이 시험판에서 보장하지 않는다.
